## 4. Known limitations

- Water phantom tests use a water-only calibration; clinical cases keep the Schneider tables, under which HU 0 is a soft-tissue blend about 1-3 % denser than water.
- The beam data library is the generic IBA library shipped with the engine, not a commissioned machine.
