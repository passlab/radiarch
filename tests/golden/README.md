# Regression goldens: provenance

Generated by radiarch, not copied from anywhere, and containing no patient data. They were captured on 2026-10-21
(commit `37afa07`) from the code paths radiarch then borrowed from OpenTPS, before radiarch's own code replaced
them; `tests/test_goldens.py` regenerates each one and compares, so the replacements must reproduce them.

| File | What it is | Made from |
|---|---|---|
| `ccc_water_10x10.npz`, `.json` | The CCC beamlet matrix (raw engine units) for a small water box and a 6 × 6 cm² field | A synthetic water box; the WiscPlan CCC engine under `engines/ccc/` |
| `geometry_simplefantom.json` | Structure index, voxel counts, density statistics and content hashes of the built geometry | The synthetic OpenTPS phantom in `tests/data/SimpleFantomWithStruct/` (see its README) |
| `proton_spots_simplefantom.json` | Energy layers and spot positions of the proton beam model | The same phantom |
| `mcsquare_inputs_simplefantom/` | The text files written for MCsquare, with absolute paths normalised; the CT block only as its SHA-256 | The same phantom |

Regenerate with `python -m radiarch.validation.goldens --capture` (see `src/radiarch/validation/goldens.py`).
